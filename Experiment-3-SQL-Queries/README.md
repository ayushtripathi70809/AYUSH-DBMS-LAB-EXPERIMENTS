Experiment 3: SQL Queries on Employee-Department-Project Database

Aim

To create an Employee-Department-Project database schema, insert sample data containing at least 30 employees, 5 departments and 8 projects, and execute queries using Selection, Projection, Aggregate Functions, GROUP BY, HAVING, CASE Expressions, and ORDER BY.

Database Tables

* Department
* Project
* Employee

Concepts Covered

1. Create Database and Tables
2. Insert Department Data
3. Insert Employee Data
4. Insert Project Data
5. Selection
6. Projection
7. COUNT()
8. SUM()
9. AVG()
10. MAX()
11. MIN()
12. GROUP BY
13. Average Salary by Department
14. HAVING
15. CASE Expression
16. ORDER BY – Ascending
17. ORDER BY – Descending
18. Combined Query

Procedure

1. Create the required database and tables.
2. Insert data for 5 departments, 8 projects and at least 30 employees.
3. Execute Selection and Projection queries.
4. Apply aggregate functions such as COUNT(), SUM(), AVG(), MAX() and MIN().
5. Execute GROUP BY and HAVING queries.
6. Use CASE expressions to categorize employee salaries.
7. Sort employee salary records using ORDER BY.
8. Execute a combined query using GROUP BY, HAVING and ORDER BY.

Source Code

The SQL source code is provided in queries.sql.

Output

The output contains the results of the SQL queries executed on the Employee-Department-Project database.

Result

The Employee-Department-Project database schema was created, sample data was inserted, and SQL queries using Selection, Projection, Aggregate Functions, GROUP BY, HAVING, CASE Expressions and ORDER BY were executed.
