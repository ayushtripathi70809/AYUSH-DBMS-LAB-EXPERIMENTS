# Experiment 10: SQL Query Optimization

## Aim

To generate a dataset containing at least 10,000 rows, identify and analyze five slow SQL queries using EXPLAIN, optimize them using indexing and query rewriting, and compare query execution time before and after optimization.

## Requirements

* MySQL 8.0 or above
* MySQL Workbench or MySQL Command Line Client

## Description

This experiment demonstrates SQL query optimization using a dataset containing at least 10,000 records. Five queries are analyzed using EXPLAIN to understand their execution plans. Indexing and query rewriting techniques are applied to improve performance, and execution times are compared before and after optimization.

## Procedure

1. Create a database and a table for storing sales records.
2. Generate at least 10,000 records.
3. Execute five SQL queries before optimization.
4. Analyze the queries using EXPLAIN.
5. Create suitable single-column and composite indexes.
6. Rewrite queries to improve index usage.
7. Execute the queries again after optimization.
8. Compare execution plans and actual execution times.

## Concepts Used

* SQL Query Optimization
* Dataset Generation
* EXPLAIN Command
* Single-Column Indexing
* Composite Indexing
* Query Rewriting
* Query Performance Benchmarking

## Expected Output

* A dataset containing at least 10,000 records.
* Execution plans for five queries before and after optimization.
* Improved index usage for suitable queries.
* A comparison of query execution times before and after optimization.

## Result

A dataset containing at least 10,000 records is generated successfully. Five SQL queries are analyzed and optimized using indexing and query rewriting. Their execution plans and actual execution times are compared to evaluate performance improvements.
