# Experiment 1: ER Diagram for E-Commerce Platform

## Aim
To design an ER diagram for an Indian e-commerce platform.

## Entities
- Customer
- Product
- Order
- OrderItem
- Seller
- Category
- Payment
- Delivery
- Address

## Concepts Covered
- Primary Keys
- Composite Attributes
- Multi-valued Attributes
- Weak Entities
- Specialization of Product
- Participation Constraints

## ER Diagram
The ER diagram will be uploaded as `ER-Diagram.png`.

## Result
The ER diagram for the e-commerce platform will be documented in this folder.
