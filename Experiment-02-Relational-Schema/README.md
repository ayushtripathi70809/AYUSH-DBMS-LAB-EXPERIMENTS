Experiment 2: Convert ER Diagram into Relational Schema

Aim

To convert the ER diagram of an Indian e-commerce platform into a relational schema and implement it using MySQL.

Description

This experiment includes creating tables with primary keys, foreign keys, and integrity constraints.

Constraints Used

* PRIMARY KEY
* FOREIGN KEY
* NOT NULL
* UNIQUE
* ON DELETE CASCADE
* ON DELETE SET NULL

Procedure

1. Convert the ER diagram into relational tables.
2. Define primary and foreign keys.
3. Apply the required integrity constraints.
4. Insert sample records.
5. Test referential integrity violations.

SQL Code

The MySQL code for table creation, sample data insertion, and constraint testing will be added in code.sql.

Output

The output will show successfully created tables, inserted records, and the results of integrity constraint tests.

Result

The ER diagram is converted into a relational schema using MySQL constraints.
